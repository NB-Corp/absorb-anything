Absorb Anything

什么都能吸纳，学到的都留下。

一个 local-first CLI，给你研读的一切安一个家：checkout、观察记录、分析、沉淀下来的知识，全是你仓库里的普通文件。

去 GitHub 快速开始

真实输出，一字节不差。每条记录都落成 .absorb/ 下的普通文件。

absorb · zsh 
$ absorb add https://github.com/sindresorhus/slugify
Added source: .absorb/sources/slugify
Observation: .absorb/sources/slugify/observations/20260828-7c318bd1aa4b.yaml
Checkout: .absorb/sources/slugify/checkout
Materials: .absorb/sources/slugify/materials
Hint: Observe changes with `absorb sync`; preserve decision-critical bytes with `absorb capture`.

$ absorb log slugify
Source log: slugify
2026-08-28T19:59:18+08:00 add normal 20260828-7c318bd1aa4b
  checkout-backed source added from https://github.com/sindresorhus/slugify

一个闭环

sources/
吸纳它
analyses/
对它下判断
knowledge/
留下经得住的

从头到尾都是文件：没有服务、没有数据库、不用注册。所有记录都收在你现有仓库的一个 .absorb/ 目录里。

Clone 一次，处处引用。

跨项目研读的成本不是磁盘，是重复读。一个工作区拥有 source 的家，其他工作区用几十字节引用它，写操作穿透到真正的家。

证据按决策计价。

随手翻翻？一条记录就是别名加日期。要采用或否决？pin 一个 commit。字节要在上游消失后活下来？带完整性哈希快照。记录决策需要的，而不是工具能测的。

为 AI agent 而生。

absorb prime 一屏给足语义；absorb explain 讲清每个对象为什么存在、何时不该用、常见误用。写操作结尾附使用现场提示，报错直接陈述正确模型而不是光拒绝。

安装

git clone https://github.com/NB-Corp/absorb-anything
cd absorb-anything
pnpm install && pnpm build
alias absorb="node $PWD/packages/absorb-anything/dist/cli.js"

预发布：尚未上 npm。需要 Node >= 22.13 与 pnpm 11。

带着你现有的工作流来。

Absorb Anything 只认领一样东西：.absorb/ 里的研读台账。不定义任务格式，也不要求你换提示词。superpowers、Trellis、OpenSpec 或自家约定照常运转：那些系统决定要建什么，这个工具留住你一路学到的东西。想要同一套磁盘格式上的建设半边？own-work 就是为此配的另一半。
